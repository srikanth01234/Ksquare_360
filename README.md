# Ksquare_360 - Construction Management System

A modern Construction Management System (ERP) built for **K SQUARE**.

## Tech Stack
- **Framework**: React 19 + Vite
- **Styling**: Tailwind CSS v4 (`@tailwindcss/vite`)
- **Icons**: Lucide React
- **Typography**: Plus Jakarta Sans

## Features
- **Dashboard**: High-level KPI metrics, project progress, expense trends, and recent activities.
- **Sites Management**: Track construction projects, site details, and plans.
- **Labour Management**: Worker directory, daily wage tracking, OT rates, and role filters.
- **Site Expenses**: Material, labour, and rental expense tracking with automated calculation.
- **Daily Updates**: Day-to-day site progress, work completion meters, and dynamic materials used logs.
- **Billing & Invoices**: Client billing, invoice generation, live tax calculation, and document preview.
- **Site Reports**: Progress and financial performance summaries with report view modals.
- **Master Data**: Centralized management for clients, employees, and construction materials with standard pricing.
- **User Management / Settings**: Roles, permissions, and site assignments.

## Getting Started

### 1. Install Dependencies
```bash
cd frontend
npm install
```

### 2. Start Development Server
```bash
npm run dev
```

### 3. Production Build
```bash
npm run build
```
